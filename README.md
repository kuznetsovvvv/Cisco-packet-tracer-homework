# Network company

Для выполнения практических заданий понадобится среда эмуляции сетевого оборудования Cisco Packet Tracer.

[Скачать Packet Tracer](https://code.s3.yandex.net/information-security/Packet_Tracer822_64bit_setup_signed.exe)

## Настройка Proxy
В окне авторизации перейдем к настройкам Proxy — Proxy Settings.  
В окне Preferences:
- **Proxy Type** — HTTP Proxy
- **URL** — 127.0.0.1
- **Port** — 3128

## 🏢 О компании

**«Одеял&ко»** — компания по производству одеял, штат сотрудников ~500 человек.

### Бизнес-процессы
- **Производство** — изготовление и контроль качества
- **Продажи** — стационарные точки + онлайн-магазин
- **Реклама и PR** — продвижение бренда

### Инфраструктура
- Головной офис (администрация, финансы, маркетинг, HR)
- Производственные цеха (оборудование, склад)
- Стационарные точки продаж

### IT-сервисы
- Электронная почта
- 1С:Предприятие
- Service Desk
- Онлайн-магазин
- FTP-сервер
- DNS-сервер

### Группы пользователей
- Маркетологи

- IT-специалисты
- Сотрудники ИБ

- Производство

## ⚙️ Конфигурация ACL

### На интерфейсе eth7/0 (Router3)

```bash
ip access-list extended DMZ 
permit tcp 10.0.0.0 0.31.255.255 10.144.0.0 0.15.255.255 eq 443
permit tcp 10.64.0.0 0.31.255.255 10.144.0.0 0.15.255.255 eq 443
permit tcp 10.96.0.0 0.31.255.255 10.144.0.0 0.15.255.255 eq 443
permit tcp 10.0.0.0 0.31.255.255 10.128.0.0 0.15.255.255 eq 25
permit tcp 10.32.0.0 0.31.255.255 10.128.0.0 0.15.255.255 eq 25
permit tcp 10.64.0.0 0.31.255.255 10.128.0.0 0.15.255.255 eq 25
permit tcp 10.96.0.0 0.31.255.255 10.128.0.0 0.15.255.255 eq 25
permit icmp any any
deny ip any any log

ip access-list extended DMZ_IN 
permit tcp any any established
permit icmp any any
```
### На интерфейсе eth8/0 (Router3)

```bash
ip access-list extended SERVERS 
permit tcp 10.32.0.0 0.31.255.255 10.160.0.0 0.15.255.255 eq 21
permit tcp 10.64.0.0 0.31.255.255 10.160.0.0 0.15.255.255 eq 21
permit tcp 10.96.0.0 0.31.255.255 10.160.0.0 0.15.255.255 eq 21
permit udp 10.0.0.0 0.31.255.255 10.192.0.0 0.15.255.255 eq 53
permit udp 10.32.0.0 0.31.255.255 10.192.0.0 0.15.255.255 eq 53
permit udp 10.64.0.0 0.31.255.255 10.192.0.0 0.15.255.255 eq 53
permit udp 10.96.0.0 0.31.255.255 10.192.0.0 0.15.255.255 eq 53
permit icmp any any
deny ip any any

ip access-list extended SERVERS_IN 
permit tcp any any established
permit udp 10.192.0.0 0.15.255.255 10.0.0.0 0.31.255.255 eq 53
permit udp 10.192.0.0 0.15.255.255 10.32.0.0 0.31.255.255 eq 53
permit udp 10.192.0.0 0.15.255.255 10.64.0.0 0.31.255.255 eq 53
permit udp 10.192.0.0 0.15.255.255 10.96.0.0 0.31.255.255 eq 53
permit icmp any any
```
