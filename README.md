# Cisco Packet tracer
Для выполнения практических заданий понадобится среда эмуляции сетевого оборудования Cisco Packet Tracer. 
[Скачать Packet Tracer](https://code.s3.yandex.net/information-security/Packet_Tracer822_64bit_setup_signed.exe)
 В окне авторизации перейдите к настройкам Proxy — Proxy Settings.
 Введите настройки в окне Preferences:
Proxy Type — HTTP Proxy;
URL — 127.0.0.1;
Port — 3128.


Компания «Одеял&ко», в которой работает около 500 человек, специализируется на пошиве мягких, как облако, одеял. 

Основные бизнес-процессы:
Производство продукции. В производственных цехах изготавливают одеяла на профессиональном оборудовании с последующим контролем качества.
Продажа продукции. Продажи идут через сеть стационарных точек продаж и онлайн-магазин, чтобы охватить широкую аудиторию покупателей.
Реклама и PR. Команда маркетологов занимается продвижением и формированием позитивного имиджа бренда для увеличения продаж и узнаваемости.

Инфраструктура компании
Для поддержания всех бизнес-процессов в «Одеял&ко» предусмотрены следующие объекты:
Головной офис — центр управления компанией, где размещаются административные, финансовые, маркетинговые и HR-подразделения.
Производственные цеха, где размещаются оборудование и складские помещения.
Стационарные точки продаж для прямого взаимодействия с покупателями, консультаций и оформления заказов.
Ключевые IT-сервисы
Электронная почта для деловой переписки и внутренней коммуникации.
«1С:Предприятие» для учёта и управления финансами, складом и персоналом.
Service Desk для поддержки сотрудников и быстрого решения технических вопросов.
Онлайн-магазин.
FTP-сервер для защищённого хранения и передачи файлов.
DNS-сервер для управления внутренними и внешними доменными именами и корпоративными веб-сервисами.
Группы пользователей
В компании несколько основных пользовательских сегментов.
Маркетологи занимаются рекламой и продвижением.
Финансисты анализируют доходы и расходы, управляют бюджетом.
IT-специалисты обеспечивают работоспособность инфраструктуры.
Сотрудники информационной безопасности контролируют защищённость всех сервисов и данных.
Консультанты занимаются оформлением и продажей заказов.
Сотрудники производства отшивают и комплектуют продукцию.





Деление адресного пространства на пользователей и сервисы
Разделите сеть 10.0.0.0/8 на две сети с равным количеством адресов в каждой.
Первую подсеть используйте для пользователей, вторую — для IT-сервисов.
Деление пользовательской подсети на подразделения
Разделите пользовательскую сеть на четыре с равным количеством адресов в каждой. Используйте получившиеся подсети в порядке возрастания для: 
маркетинга,
финансов,
сотрудников IT,
сотрудников ИБ.
Заполните столбцы «Адрес подсети», «Диапазон IP-адресов» и «Широковещательный адрес» для пользователей.
Деление сервисной подсети на сервисы
Разделите сервисную сеть на шесть с равным количеством адресов в каждой. Используйте получившиеся подсети в порядке возрастания для: 
электронной почты,
онлайн-магазина,
сервера хранения данных (FTP),
«1С:Предприятия»,
DNS-сервера,
Service Desk.
Заполните столбцы «Адрес подсети», «Диапазон IP-адресов» и «Широковещательный адрес» для сервисов.

## Задачи 
- Спроектировать инфраструктуру организации, опираясь на принципы сегментации.
- Сформировать политику сетевого доступа с учётом принципа наименьших привилегий.
- Реализовать инфраструктуру в среде эмуляции.
- Реализовать политику сетевого доступа в среде эмуляции.
